# 🔷 Geometry Dash — TypeScript Edition

Повноцінна браузерна гра **Geometry Dash**, створена з чистого аркуша на **TypeScript**, **HTML5 Canvas 2D** та **Web Audio API** без використання сторонніх важких ігрових рушіїв.

[![TypeScript](https://img.shields.io/badge/TypeScript-5.4-blue.svg)](https://www.typescriptlang.org/)
[![Vite](https://img.shields.io/badge/Vite-5.2-purple.svg)](https://vitejs.dev/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 🌟 Основні можливості

- **⚡ Точне ігрове ядро (120 Hz)**: Фіксований крок фізики та математично вивірені хідбокси з чесним запасом для трикутних шипів, як в оригінальній грі.
- **🚀 5 повноцінних ігрових режимів**:
  - **Cube**: класичний кубик з обертанням у повітрі та авто-вирівнюванням кута при приземленні.
  - **Ship**: плавне керування тягою ракети з нахилом корпусу за вектором швидкості.
  - **Ball**: перемикання гравітації при дотику до підлоги та стелі.
  - **UFO**: дискретні імпульсні стрибки у повітрі для проходження вузьких прольотів.
  - **Wave**: швидкісний рух під фіксованим кутом 45° з неоновим zigzag-шлейфом та суворою фізикою меж.
- **🎨 3D Скіни та кастомізація з фото**:
  - Завантаження будь-яких власних фотографій (`PNG`, `JPG`, `WebP`) та накладання їх як текстури на кубик, ракету, кулю, UFO та хвилю.
  - Екструзія граней кубика (об'ємний 3D-ефект із перспективним затіненням).
  - Інтерактивне 3D-прев'ю, яке можна обертати мишкою під будь-яким кутом.
  - Готові 3D-пресети: Cyber Skull, Doge Gold, Nebula 3D, Robo Matrix.
- **🎼 Автономна аудіосистема**:
  - Вбудований процедурний синтезатор EDM Synthwave (130–155 BPM).
  - Візуальна пульсація неонової підлоги та фону під біти музики через Web Audio API.
  - Процедурні звукові ефекти (стрибки, вибухи, сфери, батути, портали, чекпоінти, перемога).
  - Можливість завантажити власний MP3/WAV трек.
- **🏆 6 культових офіційних рівнів з каруселлю**:
  1. 🔵 **Stereo Madness** *(Easy, ★ 1, 130 BPM)*
  2. 🟢 **Back On Track** *(Normal, ★ 2, 135 BPM)*
  3. 🟠 **Polargeist** *(Hard, ★ 3, 140 BPM)*
  4. 🔴 **Dry Out** *(Harder, ★ 4, 142 BPM)*
  5. 🟣 **Electroman** *(Insane, ★ 8, 150 BPM)*
  6. 😈 **Clubstep** *(Demon, ★ 10, 155 BPM)*
- **🌐 Розділ «Карти гравців та спільноти»**:
  - Вбудовані рівні від авторів (*Neon Dreams*, *Cyber Sonic*, *Fire Aura*).
  - Збереження, імпорт та експорт карт у форматі JSON.
  - Відстеження прогресу (%) для кожної карти.
- **✏ Повнофункціональний візуальний редактор рівнів**:
  - Сітка 30x30 з прив'язкою.
  - Палітра блоків, напівблоків, шипів, сфер (Yellow, Pink, Red, Blue), батутів, порталів режимів, гравітації та швидкості, монет і фінішу.
  - Обертання об'єктів (`R`), інструменти встановлення та стирання.
  - **Вертикальне регулювання висоти камери**: плавне переміщення вгору/вниз клавішами `W`/`S`, коліщатком миші або спеціальним слайдером висоти на панелі.
  - Тестування рівня в один клік прямо з редактора.
- **◆ Режим практики (Practice Mode)**:
  - Встановлення зелених контрольних точок (`Z`) та їх видалення (`X`).
  - Миттєвий респаун на останньому чекпоінті.

## 🎮 Керування

| Дія | Клавіша / Керування |
|---|---|
| **Стрибок / Тяга ракети та хвилі** | `Пробіл` / `Стрілка Вгору` / `W` / `Клік миші` |
| **Пауза / Меню** | `Escape` |
| **Поставити чекпоінт (Практика)** | `Z` |
| **Видалити чекпоінт (Практика)** | `X` |
| **Скролінг камери в редакторі** | `A` / `D` або стрілки `Ліворуч` / `Праворуч` |
| **Висота камери в редакторі (Вгору/Вниз)** | `W` / `S`, стрілки `Вгору` / `Вниз` або **Коліщатко миші** |
| **Поворот об'єкта в редакторі** | `R` |
| **Видалення об'єкта в редакторі** | `Права кнопка миші` або режим `Стерти` |

## 🚀 Встановлення та локальний запуск

### Вимоги:
- [Node.js](https://nodejs.org/) (версія 18 або новіша)

### Кроки запуску:
```bash
# 1. Клонуйте репозиторій
git clone https://github.com/<ваш-username>/<назва-репозиторію>.git
cd <назва-репозиторію>

# 2. Встановіть залежності
npm install

# 3. Запустіть сервер розробки
npm run dev
```

Після запуску гра відкриється за адресою: **http://localhost:3000/** (або іншому доступному порту).

### Збірка для продакшну:
```bash
npm run build
```
Зібрані оптимізовані файли будуть створені в папці `dist/`.

## 📦 Розгортання на GitHub Pages

Проєкт вже налаштований з відносними шляхами (`base: './'`). Щоб опублікувати гру на GitHub Pages:
1. Перейдіть у репозиторії на GitHub: **Settings** -> **Pages**.
2. У розділі **Build and deployment** виберіть **GitHub Actions** або гілку з папкою `dist`.
3. Ваша гра стане доступною всьому світу онлайн безкоштовно!
